Kasukabe Defense Stickers

Install guide — takes about 2 minutes, one time only

What this is

A browser add-on that lets you send stickers in Google Meet's in-call chat. Click a button, pick a sticker, and it shows up as a real picture in the chat — for everyone else who also has this installed.

Install it

  1. You should already have this folder unzipped somewhere. Keep it — don't delete it after installing, your browser keeps reading the extension straight from it.
  2. Open Chrome (or Edge / Brave) and go to chrome://extensions — type or paste that into the address bar and hit Enter.
  3. Turn on Developer mode — it's a toggle switch, usually top-right of the page.
  4. Click the Load unpacked button that appears once Developer mode is on.
  5. In the folder picker, select this folder — the one this file is sitting in, the one with manifest.json inside it.
  6. Chrome shows a small permissions notice (something like "read and change your data on meet.google.com"). Click Add extension / Confirm — that's normal, it's just how the sticker button gets added to the chat.
  7. Done. You won't need to repeat this unless you delete the folder.
⚠️ Already had a Google Meet tab open before you did this? Refresh that tab now (press F5) — the sticker button will not appear on a tab that was already open. This is the single most common thing people get stuck on, not the install itself. A Meet tab you open after installing works immediately, no refresh needed.

Use it

  1. Go to meet.google.com and join or start a call.
  2. Open the in-call chat panel (the message bubble icon).
  3. Look for a small round 🩹 button next to the message box — click it.
  4. A tray pops up with all the stickers, grouped into packs, with a search box on top. Type to search, or scroll.
  5. Click a sticker — it's sent to the chat automatically.
Please read this part: stickers only show up as real pictures for people who also have this extension installed. Someone without it sees a short line of text instead (like :stkr:praise/jhakaas:) — that's expected, not a bug. Once everyone in the group installs it, it works for all of you.

New stickers added later show up for you automatically — no reinstall needed for that. You only need to reinstall if the button itself stops working after a Google Meet update (rare, and we'll tell you when that's the case).

If something looks broken

Button not showing? Refresh the Meet tab (see the red box above if you had it open before installing), and make sure the chat panel is actually open.

Stickers not sending? Click directly in the chat box once, then try the sticker again.

Still stuck? Open the sticker tray, press F12 for DevTools, click the Console tab, look for lines starting with [KDS], and share what you see.
